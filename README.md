# 阿角的三角旗節｜四年級三角形探索繪本

四年級上學期「三角形」單元的互動數學繪本網站。學生跟著小三角形阿角，在形狀鎮的「三角旗節」裡完成六章任務，每完成一章得到一面三角旗。

## 章節

1. **誰是真正的三角形？**　判斷三角形（圓角、缺口、彎邊、出頭都不是）
2. **用線段圍住花**　最少三條線段圍成封閉圖形；頂點、邊、角
3. **依邊長分隊**　量邊長分類；等腰三角形（腰、底、頂角、底角）、正三角形
4. **依角排隊伍**　用直角板比較角的大小；銳角、直角、鈍角三角形；最多一個直角
5. **自己畫三角旗**　依條件畫直角、等腰、正三角形並說明理由
6. **雙胞胎旗子**　平移、旋轉、翻面疊合判斷全等，找對應頂點
7. **終章　三角旗節**　總複習與小老師活動

每章最後都有「阿角的想法」（常見迷思），適合全班討論。

## 使用

直接開啟網站即可，手機、平板、電腦都能用。所有操作都在學生的裝置上進行，不上傳任何資料；進度只存在該裝置的瀏覽器裡。

純 HTML／CSS／JavaScript，不需要安裝或建置。
